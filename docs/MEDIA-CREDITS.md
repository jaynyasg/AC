# Image credits

Section photographs on the site are self-hosted copies from Wikimedia Commons. CC BY and CC BY-SA files require credit, a link to the license, and a note that the copy here was resized. Each file was opened and checked before it was used: glossy ice, glacier, snow, or frost, with no trees, grass, sandy beaches, cities, people, or objects.

Every screen size uses the same full-frame photograph, sized with `object-fit: cover` so the ice fills the section without tiling. Copies below were resized to 2560px wide where the original was larger.
